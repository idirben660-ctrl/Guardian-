GUARDIAN PWA — first prototype

What it does:
- App-like black/red mission dashboard.
- Generates safe training/readiness/volunteer-style missions.
- Saves mission count locally.
- Requests notification permission.
- Works offline after the first successful load.

Important:
This is NOT an emergency dispatch system and does not receive police/ambulance reports.

To use on iPhone:
1. Put these files on an HTTPS website (GitHub Pages is a simple option).
2. Open the site in Safari.
3. Share -> Add to Home Screen.
4. Open it from the Home Screen.
5. Tap ENABLE ALERTS.

For true background push notifications, the next version needs a push-notification backend (for example Web Push/FCM/APNs-compatible infrastructure) and HTTPS.
